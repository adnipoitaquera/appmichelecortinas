# Michele Cortinas — Next.js

Conversão do sistema original para Next.js, preservando os textos, o layout, os estilos e a lógica JavaScript existentes.

## Executar

```bash
npm install
npm run dev
```

Os arquivos CSS e JavaScript externos do sistema original estão em `public/` e são carregados na ordem esperada pelo sistema legado.
